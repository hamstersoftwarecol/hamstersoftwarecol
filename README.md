## Hola, somos Hamster Software 👋

Creamos soluciones digitales para empresas que quieren mejorar sus procesos y crecer con tecnología. Trabajamos desde la idea hasta la implementación, conectando las necesidades de cada negocio con aplicaciones prácticas y fáciles de usar.

En este espacio compartimos proyectos de software empresarial, comercio electrónico y plataformas de servicios.

## Qué construimos

- **Aplicaciones web:** plataformas empresariales, portales y sistemas de gestión.
- **Comercio electrónico:** tiendas virtuales y experiencias de compra conectadas con WhatsApp.
- **Aplicaciones móviles:** soluciones para iOS y Android.
- **Datos e IA:** análisis, dashboards y automatización con inteligencia artificial.
